# Krescendo

Tienda demo responsive de K-pop merch, lista para desplegar como sitio estático.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel, importa el repositorio.
3. Framework Preset: `Other`.
4. Build Command: vacío.
5. Output Directory: `dist`.

El inicio de sesión incluido es una interfaz de demostración. Para cuentas reales, conecta un proveedor como Clerk, Auth0 o Supabase Auth y configura sus variables en Vercel.
